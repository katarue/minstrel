# Minstrel デザインシステム定義書

**バージョン**: 1.0  
**作成日**: 2026年5月7日  
**ステータス**: 確定（フェーズ1の実装根拠ドキュメント）

このドキュメントは、Minstrelプロジェクトのビジュアルデザインに関するすべての決定事項を集約したものである。Claude Codeはこのドキュメントを実装の根拠として参照する。

---

## 1. ブランディング基盤

### 1-1. コアコンセプト

**「ギルドの掲示板」**

吟遊詩人（Minstrel）たちが集まるギルドの集会所。古い木の壁に張り出された羊皮紙には、各地で行われる演奏会の情報が並ぶ。冒険から帰った戦士たちが、酒杯を傾けながら次にどの演奏会に足を運ぶか語り合う場所。

このコンセプトはMinstrel（吟遊詩人）というブランド名と完全に呼応している。

### 1-2. キーワード

- ノスタルジック（最重要）
- 重厚だが親しみやすい
- トラディショナル
- レトロ
- 中世ヨーロッパ的
- ギルド・酒場の温もり

### 1-3. ターゲットユーザー

- 30〜50代男性中心
- 仕事で活躍しながら、休日に子供心に戻りたい層
- 音楽リテラシーが高く、生演奏を楽しみたい
- 知性・教養・経済的余裕がある
- ストリーミングだけでは物足りないと感じている

### 1-4. ターゲット感情

「秘密のギルドに迎え入れられたような、知的な高揚感と懐かしさ」

## 2. カラーシステム

### 2-1. パレット名

**「羊皮紙と深紅（Parchment & Crimson）」**

### 2-2. カラー定義

| 役割 | 色名 | カラーコード | 用途 |
|------|------|------------|------|
| 背景（メイン） | クリーム羊皮紙 | `#F5EFE0` | ページ全体の背景 |
| 背景（サブ） | 古紙 | `#EBE2CC` | カード背景、セクション背景 |
| メインカラー | ディープ・ボルドー | `#722F37` | ロゴ、主要ボタン、リンク |
| アクセントカラー | アンティーク・ゴールド | `#B89D5E` | 装飾線、強調要素、ハイライト |
| テキスト（本文） | 濃焦茶 | `#3B2F1D` | 標準的な本文 |
| テキスト（見出し） | 黒に近い茶 | `#1F1A12` | 大見出し、強調テキスト |

### 2-3. ステータスカラー（追加定義）

| 用途 | カラーコード |
|------|------------|
| 成功（チケット販売中など） | `#5C7A3E`（深い緑） |
| 警告（残席少など） | `#B85C28`（赤茶） |
| エラー（キャンセル・中止） | `#8B2E2E`（暗赤） |
| 情報（一般通知） | `#4A5568`（チャコールグレー） |

### 2-4. 配色ルール

- **70:25:5の法則**を遵守：背景70%、メインカラー25%、アクセント5%
- **WCAGコントラスト比 4.5:1以上**を保証
- 暖色系で統一、寒色は使用しない（ステータスカラーの一部を除く）

### 2-5. ライト/ダークモード

**ライトモードのみ実装する**（フェーズ1ではダークモード非対応）。

理由：
- 羊皮紙の世界観はライトモードに最適化されている
- ダークモード対応は実装コスト増
- 必要になればフェーズ後半で追加検討

## 3. タイポグラフィ

### 3-1. フォント選定

**「クラシック書物（Classic Manuscript）」**

| 用途 | フォント | 配信元 |
|------|---------|--------|
| 見出し（英） | Cinzel | Google Fonts |
| 見出し（日） | Noto Serif JP（Bold） | Google Fonts |
| 本文（英） | EB Garamond | Google Fonts |
| 本文（日） | Noto Serif JP（Regular） | Google Fonts |

すべてGoogle Fontsから無料・商用利用可。

### 3-2. フォントサイズ階層

```
H1: 2.5rem (40px) / Cinzel Bold / Noto Serif JP Bold
H2: 2rem (32px) / Cinzel SemiBold / Noto Serif JP Bold
H3: 1.5rem (24px) / Cinzel Medium / Noto Serif JP Medium
H4: 1.25rem (20px) / EB Garamond Bold / Noto Serif JP Medium
本文: 1rem (16px) / EB Garamond Regular / Noto Serif JP Regular
キャプション: 0.875rem (14px) / EB Garamond Regular / Noto Serif JP Regular
```

### 3-3. 行間・文字間隔

- 本文の行間：1.7（読みやすさ重視）
- 見出しの行間：1.3
- 文字間隔：見出しは標準、本文は0.02emほど広めに

## 4. ロゴシステム

### 4-1. ロゴの構造

エンブレム型（円形フレーム）+ ブランド名テキストの分離構成。

### 4-2. シンボル

**剣＋ハープのクロスデザイン**

- 中世ヨーロッパの剣と吟遊詩人のハープをX字に交差
- 「ゲーム（剣）」と「音楽（ハープ）」の両方を一発で連想させる
- シンプル線画ベース、シルエットでも認識可能

### 4-3. ブランド名テキスト

**「MINSTREL」** をCinzelフォントで表記。

サブタイトル「Game Music Concert Portal」を併記する場合は、EB Garamondで控えめに。

### 4-4. ロゴバリエーション

最低限以下を用意する：

1. **プライマリーロゴ**：シンボル + 横にMINSTRELのテキスト（Webヘッダー用）
2. **シンボル単体**：剣＋ハープのエンブレムのみ（ファビコン、SNSアイコン用）
3. **テキストのみ版**：MINSTRELの文字だけ（控えめな署名用）
4. **モノクロ版**：印刷物・モノクロ媒体対応

### 4-5. ロゴカラー

- 標準：ボルドー（`#722F37`）の単色
- 装飾的バリエーション：ゴールド（`#B89D5E`）の縁取り可
- モノクロ版：ダークブラウン（`#1F1A12`）

## 5. レイアウト・形状

### 5-1. レイアウト密度

**ゆったり〜中程度**

- カード間隔：広めに取る（24〜32px）
- 見出しと本文の間：十分な余白（16〜24px）
- 画面の左右：適度な余白（PC: 80px以上、SP: 16px）

### 5-2. 角の丸み（Border Radius）

**軽い角丸：4〜8px**

- カード：6px
- ボタン：4px
- バッジ：4px
- 入力フィールド：4px

### 5-3. 影・立体感

**軽い影、茶色系の暖かい影**

CSS定義例：
```css
box-shadow: 0 2px 8px rgba(59, 47, 29, 0.12);
/* hover時: */
box-shadow: 0 4px 16px rgba(59, 47, 29, 0.18);
```

### 5-4. 区切り線

- 標準区切り：細い装飾線（1px、ゴールド `#B89D5E`、透明度50%）
- セクション区切り：余白で表現
- 装飾的な区切り：古典的な音符記号や装飾モチーフを1つ配置

## 6. カードデザイン

### 6-1. カード形状

**羊皮紙カード型（縦長グリッド）**

- 画像：上部に16:9で配置
- 情報：下部にイベント情報（タイトル、日時、場所、ジャンルバッジ）
- 影：軽い影で「机に置かれた羊皮紙」感を演出

### 6-2. グリッドレイアウト

- PC（1200px以上）：4列
- タブレット（768〜1199px）：3列
- スマホ（〜767px）：1列

### 6-3. ホバーエフェクト

**軽いリフトアップ + 影の濃化**

```css
transition: all 0.2s ease;
/* hover時: */
transform: translateY(-4px);
box-shadow: 0 4px 16px rgba(59, 47, 29, 0.18);
```

## 7. 画像・ビジュアル

### 7-1. キービジュアルの扱い

各コンサートのチラシ画像をカード上部に大きく表示。詳細ページではオリジナル比率を尊重する。

### 7-2. 画像のトリミング比率

**カード一覧：16:9（横長）**  
**詳細ページ：オリジナル比率（縦長チラシそのまま）**

理由：一覧では揃って見やすく、詳細では情報を欠落させない。

### 7-3. 画像取得の優先順位

画像は以下の優先順位で取得・表示する。

1. **公式チラシ画像**（スクレイピングで取得、Supabase Storageに自前保存）
2. **演奏曲目の公式パッケージ画像**（Amazon等から取得、商用利用OKなもののみ）
3. **Pythonで動的生成する簡易サムネイル**（タイトル名 + ロゴ + 羊皮紙背景）

3の動的生成サムネイルの仕様：
- 背景：羊皮紙テクスチャ（クリーム色 `#F5EFE0`）
- 中央：ロゴのシンボル（剣＋ハープ）を控えめに配置
- 下部：イベントタイトルをCinzel + Noto Serif JPで配置
- 装飾：ゴールドの細い枠線

### 7-4. 画像ホスティング

すべての画像はSupabase Storageに自前保存する。**ホットリンク禁止**。

## 8. アニメーション・インタラクション

### 8-1. ホバーエフェクト

カードにマウスを乗せると、わずかに浮き上がり影が濃くなる（上記6-3参照）。古書を持ち上げるような感覚。

### 8-2. ページ遷移

**アニメーションなし、即時遷移**。情報を素早く確認したいユーザーを優先。

### 8-3. スクロール挙動

**標準的なスクロール**。パララックス効果は使用しない。

### 8-4. その他のインタラクション

ボタンのhover：軽いカラー変化のみ。複雑なアニメーションは避ける。

## 9. 音楽サイト特有の要素

### 9-1. ジャンルバッジ

カードの右上に小さく表示。

| ジャンル | カラー |
|---------|--------|
| オーケストラ | `#722F37`（ボルドー） |
| 吹奏楽 | `#B89D5E`（ゴールド） |
| バンド・ロック系 | `#5A3A22`（ダーク茶） |
| アコースティック | `#EBE2CC`（羊皮紙ベージュ、文字は濃茶） |
| 室内楽 | `#4A5568`（チャコール） |
| その他 | `#3B2F1D`（濃焦茶） |

### 9-2. 装飾モチーフ

- セクション区切りに音符記号を1つ
- ヘッダー装飾に五線譜の罫線（控えめに）
- フッターに古典的な楽器イラスト

過剰にならないようポイント使い。

### 9-3. 「音」のビジュアライズ

**使用しない**。波形・五線譜アニメーション等は世界観と合わない。

## 10. レスポンシブ対応

### 10-1. ブレイクポイント

```
モバイル: 〜767px
タブレット: 768px〜1199px
デスクトップ: 1200px〜
```

### 10-2. モバイル最適化方針

- カードは1列表示
- ヘッダーはハンバーガーメニュー
- 画像サイズは画面幅に合わせて自動調整
- フォントサイズは大型化（本文 16px → 18px）

## 11. アクセシビリティ

### 11-1. 必須対応

- WCAG 2.1 Level AAコンプライアンス
- カラーコントラスト 4.5:1以上
- altテキストの完全付与
- キーボードナビゲーション対応
- 適切なセマンティックHTML

### 11-2. フォントサイズ・コントラスト（Tailwind 実装制約）

**フォントサイズ**

| 用途 | 最小クラス | px |
|---|---|---|
| 本文・説明文・データセル | `text-sm` | 14px |
| UIラベル・列ヘッダー・バッジ等クローム | `text-xs` | 12px |
| ピクセル直書き（`text-[Npx]`） | **禁止** | — |

**テキスト透明度（`text-ink-body/N`）**

| 用途 | 最小 opacity |
|---|---|
| 主要コンテンツ（日時・会場・イベント名） | 修飾なし（`text-ink-body`） |
| 副次コンテンツ（都道府県・主催者・説明文） | `/80` |
| UIクローム（ヘッダー・列ラベル・補助リンク） | `/70` |
| プレースホルダー・disabled 状態のみ | `/50` 以下を許容 |

`/60` 以下をコンテンツ目的で使うことは **禁止**。

## 12. 実装上の注意

### 12-1. Tailwind CSSとの統合

カラー定義をtailwind.config.tsに反映する。

```typescript
theme: {
  extend: {
    colors: {
      parchment: {
        DEFAULT: '#F5EFE0',
        dark: '#EBE2CC',
      },
      bordeaux: '#722F37',
      gold: '#B89D5E',
      ink: {
        body: '#3B2F1D',
        heading: '#1F1A12',
      },
    },
    fontFamily: {
      heading: ['Cinzel', 'Noto Serif JP', 'serif'],
      body: ['EB Garamond', 'Noto Serif JP', 'serif'],
    },
  },
}
```

### 12-2. Google Fontsの読み込み

`web/src/app/layout.tsx` でNext.jsの`next/font/google`を使用して最適化する。

### 12-3. アクセシビリティ検証

実装後、Chrome DevToolsのLighthouseでアクセシビリティスコア90以上を目標とする。
