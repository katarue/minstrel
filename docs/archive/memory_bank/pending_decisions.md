## P-001：Badge.tsx の chamber カラーリファクタリング

**優先度**: 低  
**内容**: Badge.tsx の `chamber`（室内楽）バリアントが `bg-info` を再利用している。意味論的に「室内楽」と「情報ステータス」が同じ変数を共有しているのは将来的に問題になる可能性  
**現状の影響**: 結果的に正しいカラーコード（#4A5568）になっているので実害なし  
**検討タイミング**: ステータスカラーとジャンルカラーの分離が必要になった時、または余裕ができた時  
**対応案**: chamber専用のCSS変数（--color-chamber）を追加するか、`bg-[#4A5568]` の直接指定に変更
